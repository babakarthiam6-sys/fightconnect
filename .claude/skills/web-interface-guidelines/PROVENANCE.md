# Provenance

Ce skill n'est **pas** une copie du skill `web-design-guidelines` de
`vercel-labs/agent-skills` : ce dépôt-là ne porte aucune licence (ni fichier
`LICENSE`, ni champ `license` dans son `package.json`), donc son contenu n'est
pas redistribuable dans ce dépôt.

Le fichier ci-contre a été écrit pour ce projet. Il reproduit le mécanisme, qui
est trivial et n'appartient à personne : aller chercher les règles publiques à
l'exécution plutôt que de les figer.

Les règles elles-mêmes viennent de
https://github.com/vercel-labs/web-interface-guidelines (dépôt licencié, et
récupéré à chaud, jamais copié ici).

Pour installer le vrai skill de Vercel plutôt que celui-ci, sur une machine :

    npx skills add vercel-labs/agent-skills
